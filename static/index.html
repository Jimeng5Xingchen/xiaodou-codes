使用说明

本站简介　聚合 B 站、豆瓣小组、微博、知乎、贴吧、微信公众号、小红书、抖音等社区公开分享的小豆（豆包旗下 AI 个人助理）邀请码， 并调用豆包官方接口校验每个码是否真实有效。豆瓣小组讨论与评论区会自动抓取，抓到的码同样经官方接口前置校验。

邀请码分类　码池按来源分为「站内分享」「站外分享」「自动采集」三类，可用分类栏筛选；站内分享码不显示来源，只展示分享者。 按「排序」可切换默认 / 最新 / 最早 / 即将过期 / 多源命中。列表每 25 秒自动刷新一次。

今日码池推荐　从今天新收录的可用码里推荐一个，点「更换一下」看下一个，点「已使用」会把它标记掉并换一个。

多源命中 / 回复评论　同一个码被多个来源命中时，会显示「N 源命中」；点击它可查看分别命中了哪些来源、逐条直达原文， 并展开每个来源下的回复 / 评论内容。

提交邀请码　站内共享码：仅填邀请码、需登录，展示为你分享；站外分享码：可填邀请码或分享链接，自动识别链接来源，别人可一键直达原文。

关于　本站为个人自用的临时工具，聚合的均为公开可见内容，与豆包 / 字节跳动无任何关联。

状态说明　「官方校验有效」= 豆包官方邀请页接口返回该码存在且未过期；「待确认」= 社区标注可能可用但官方接口未识别； 「社区反馈已用」= 社区反馈已被使用；「已过期」= 官方接口显示已过期。

社区来源　豆瓣小组讨论 / 评论、B 站搜索 / 评论可直接站内抓取；微博 / 知乎 / 贴吧 / 微信公众号 / 小红书 / 抖音多需登录， 站内仅抓取其公开可见内容并以官方接口校验；抓不到的用「社区找码」直达入口前往查看。豆瓣有访问频率限制，站内以缓存方式低频抓取。

外观设置　标题右侧的按钮可打开外观设置：外观主题支持「跟随系统 / 暗黑 / 亮色」，跟随系统会随你的系统浅色深色模式自动切换； 外观颜色提供 7 个预设色与自定义取色器，设置保存在本机浏览器。

材质与形状　「毛玻璃水晶效果」可开关，启用后卡片、按钮、弹窗变为半透明磨砂质感并带水晶切面描边； 「玻璃微调」里可调表面透明度（0%~100%）、背景模糊（0~40px）与水晶高光强度。 「胶囊形状」把按钮与卡片转为安卓 11 的药丸轮廓；「安卓 11 风格」开启 Material You 动态取色、超椭圆圆角与点击涟漪； 「动效」控制光晕漂移与点击反馈。全部设置保存在本机浏览器，PC / 手机端各自适配。

我分享的邀请码　「我的账号」页下方可折叠查看你分享的邀请码，默认只显示前 20 个（表格形式，含状态、来源、时间）， 点开可展开全部；点击码即可复制。

管理页　管理员登录后，导航栏会多出「管理」入口，可管理：系统邮箱授权（登记 SMTP 发件邮箱与授权码，可设默认发件人）、 注册策略（是否开放新用户注册、是否允许含特殊符号的邮箱、邮箱白名单）、用户组（给用户做分类）、 用户治理（改分类、封号 / 解封、重置密码、设为管理员、删除账号）。系统始终保留至少一个可用管理员，且不能封禁或删除自己。

初始部署　首次访问时会弹出「初始化部署」引导，填写登录账号、绑定邮箱与密码即可创建第一个管理员； 之后进入「管理 → 系统邮箱授权」补充 SMTP 账号即可正常发送验证码。

注销账号　「我的账号」页底部提供「注销账号」，需输入登录密码确认。注销会清除个人资料、密码与全部分享记录，且不可恢复； 若只是想退出，点「退出登录」即可。

隐私　本站不收集任何账号 Cookie / 登录凭证。抓取书签只读取你自己浏览器里当前页面的公开文字。

部署　前端可独立托管到 Cloudflare Pages（静态资源全球 CDN、流量免费无限）， 后端仍跑在本服务上：?api=https://后端地址 可临时切换后端。 前端托管在 Pages 时跨域调用，后端已放行 CORS 与登录态自定义头。

免责　邀请码使用规则以小豆 App 页面为准。本站不提供任何付费码、账号或代激活服务。
